Ultimatrix Web Flasher

Install a clock face on your ESP32 over USB, straight from the browser.

  1. ConnectPlug the clock board into this computer with a data-capable USB cable.
  2. Pick a faceEach face is its own image. You can switch faces later from the clock's settings page.
  3. InstallPress Install, choose the board's serial port and wait for it to finish.
This browser has no Web Serial support. Use Chrome, Edge or Opera on a desktop.

Good to know

  • A fresh install erases the device, including Wi-Fi and settings. Untick "Erase" to keep them.
  • After installing, join the UM-SETUP Wi-Fi network (or scan the QR code on the panel) to set up Wi-Fi. Later updates come over Wi-Fi from the clock's settings page.
  • Flashing needs HTTPS (or localhost) and a Chromium-based desktop browser.
  • Signed update files and source: update downloads, GitHub.
