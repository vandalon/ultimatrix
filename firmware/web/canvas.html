How this works
  1. Choose a source and get a free key. KLIPY: create an API key in the partner panel at partner.klipy.com (a new key is limited to 100 requests an hour until KLIPY approves it). GIPHY: sign in at developers.giphy.com, create an app (choose API, not SDK) and copy its key.
  2. Paste the key above and press Save key. Each source keeps its own key. It is stored on the clock (anyone who can open this page on your network can read it), so you only do this once.
  3. Search, then tap a GIF. Still pictures open a crop square; animated GIFs are loaded as frames (up to 64, as many as fit) into the clock's memory and play at once.
  4. An imported GIF is kept in the clock's memory only: it is gone when WLED stops or the clock restarts. Pictures and drawings you press Save as new for are kept on the clock.
This device needs internet access for the search (the clock does not). Animated import needs Chrome or Edge; Safari and the WLED app load the first frame only. The free key allows about 100 searches an hour.
